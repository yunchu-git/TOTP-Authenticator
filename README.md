# TOTP-Authenticator
TOTP客户端Python脚本开源

> [!IMPORTANT]
> **本软件使用MIT协议，在分发时请保留协议原文并署名！谢谢！**

在使用PyPi等网站时，可能会遇到多重验证（2FA）的限制，于是只能使用手机的微软验证器等进行登录，对开发者而言十分不便，而本软件就是用来解决本问题的。

本软件的好处：  
- 🔒**安全性高**所有配置均保存在用户电脑上的accounts.ini上，降低了互联网暴露风险  
- 🖥️**简单易用**软件整体采用简约风格，无广告，可以快捷使用各种功能  
同时也请注意：**本软件只支持Windows10以上电脑，并且仅支持Windows电脑**
